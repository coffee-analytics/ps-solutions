# ods.web_forms_hatcher_mirage_form

## Система-источник

Веб-формы: пользователи вносят данные в форме "Мираж".

## Описание таблицы

Результаты миража — овоскопирования яйца на просвет (этап «Мираж»). Одна запись — итоги проверки: количество яиц с погибшим эмбрионом (`count_dead_embryon`) и пустых, неоплодотворённых яиц (`count_emty_egg`), дата миража и применённая вакцина. Результаты миража записываются по 1-2 инкубационным телегам скопом, потому что на производственную линию миража ставится сразу 2 телеги. Это значит, что, зачастую, мы не знаем тут результаты миража до конкретной телеги, но знаем результаты по парам телег. Далее для аналитической отчетности результаты миража (выбраковка) могут распределяться по телегам пропорционально количеству яиц в телеге.

## Описание колонок

| Колонка | Тип | Описание | Пример данных |
| :--- | :--- | :--- | :--- |
| `count_dead_embryon` | integer | Количество яиц с погибшим эмбрионом (выявлено при миражировании) | 1, 0, 580, 200 |
| `count_emty_egg` | integer | Количество пустых (неоплодотворённых) яиц (выявлено при миражировании) | 1, 100, 0, 280 |
| `vaccine` | character varying | Наименование применённой вакцины | Test vaccine, test-vac, аап, Nobilis IB+ND+EDS |
| `date` | date | Дата проведения миража | 2026-06-09, 2026-04-20, 2026-03-07 |
| `id` | integer | Идентификатор записи миража | 5, 4, 3, 2, 1 |
| `added_at` | timestamp without time zone | Дата и время создания записи | 2026-05-25 17:46:05, 2026-06-09 08:38:44 |
| `update_at` | timestamp without time zone | Дата и время последнего обновления записи | 2026-05-14 09:34:26, 2026-06-09 14:49:12 |
| `employee_add_id` | integer | Идентификатор сотрудника, создавшего запись | 23, 39 |
| `employee_upd_id` | integer | Идентификатор сотрудника, обновившего запись |  |
| `tech_load_ts` | timestamp without time zone | Техническое поле: дата и время загрузки записи в ODS-слой | 2026-06-24 08:01:46 |
