# dbo.b24Tasks

## Система-источник

Bitrix24 CRM — сущность «Задача» (Tasks). Портал-источник не уточнён отдельным полем `b24_name` — проверить по значению `b24_name` в данных.

Официальная документация REST API:
- [Обзор методов Tasks REST API](https://apidocs.bitrix24.com/api-reference/tasks/index.html)
- [Список полей задачи (Task Fields)](https://apidocs.bitrix24.com/api-reference/tasks/fields.html)
- [tasks.task.getFields — получение списка полей задачи](https://apidocs.bitrix24.com/api-reference/tasks/tasks-task-get-fields.html)
- [tasks.task.list — получение списка задач (в т.ч. поле `TAGS`)](https://apidocs.bitrix24.com/api-reference/tasks/tasks-task-list.html)
