## Описание колонок

| Колонка | Тип | Описание | Пример данных |
| :--- | :--- | :--- | :--- |
| `id` | bigint | Внутренний идентификатор записи в ODS-таблице (суррогатный ключ), не является полем Bitrix24 API. | 681365, 681757, 681588, 681728, 683354 |
| `comp_b24_id` | bigint | Идентификатор компании в CRM Bitrix24 (поле `ID` сущности «Компания»). | 147, 5091, 1669, 5657, 8631 |
| `comp_pss_id` | bigint | Внутренний идентификатор компании в системе PS Solution (не поле Bitrix24 API; см. также `dbo.Companies.comp_pss_id`). | 4926, 4712, 4299, 4872, 4213 |
| `comp_point_id` | bigint | Внутренний идентификатор точки/АЗС в системе PS Solution (не поле Bitrix24 API). | 66455, 35444, 66453, 11071, 50406 |
| `comp_name` | text | Название компании/бренда. Прямого одноимённого поля в стандартной схеме CRM Bitrix24 нет; вероятно соответствует полю `TITLE` компании либо кастомному полю — требует проверки в конкретном портале. | Лукойл, Роза Мира, Teboil, Лукойл, Лукойл |
| `comp_point_name` | text | Название точки/АЗС. Кастомное поле, отсутствует в стандартной схеме CRM Bitrix24 — уточнить через `crm.company.userfield.list` в портале-источнике. | 13225 Рождественно, 78125 Осиновая роща, 77528 Азовская, 13212 Атяшево, 34457 Палласовка |
| `comp_partner_name` | text | Название партнёра/группы АЗС. Кастомное поле, отсутствует в стандартной схеме CRM Bitrix24 — уточнить через `crm.company.userfield.list`. | Л-СЗНП, Л-УНП, ИП Черникова, М10, Л-ЦНП |
| `comp_region` | text | Регион расположения точки/АЗС. Кастомное поле, отсутствует в стандартной схеме CRM Bitrix24 — уточнить через `crm.company.userfield.list`. | Вологда / Вологодская область, Республика Удмуртия, Вологда / Вологодская область, Казань, Рязань |
| `comp_tech_setup` | text | Тип технического оснащения точки (видеорегистратор / сервер ГБ / сервер PSS). Кастомное поле, отсутствует в стандартной схеме CRM Bitrix24 — уточнить через `crm.company.userfield.list`. | Видеорегистратор, Видеорегистратор, Видеорегистратор, Сервер ГБ, Видеорегистратор |
