## Описание колонок

| Колонка | Тип | Описание | Пример данных |
| :--- | :--- | :--- | :--- |
| `id` | bigint | Внутренний идентификатор записи в ODS-таблице (суррогатный ключ), не является полем Bitrix24 API. | 495831, 493676, 493695, 493709, 493909 |
| `comp_b24_id` | bigint | Идентификатор компании в CRM Bitrix24 (поле `ID` сущности «Компания»). | 3898, 3224, 4832, 3328, 5006 |
| `comp_pss_id` | bigint | Внутренний идентификатор компании в системе PS Solution (не поле Bitrix24 API; см. также `dbo.Companies.comp_pss_id`). | 5100, 4931, 4000, 2119, 4723 |
| `comp_point_id` | bigint | Внутренний идентификатор точки/АЗС в системе PS Solution (не поле Bitrix24 API). | 33003, 50270, 11188, 16112, 11135 |
| `comp_name` | text | Название компании/бренда. Прямого одноимённого поля в стандартной схеме CRM Bitrix24 нет; вероятно соответствует полю `TITLE` компании либо кастомному полю — требует проверки в конкретном портале. | Лукойл, Лукойл, Лукойл, Лукойл, Лукойл |
| `comp_point_name` | text | Название точки/АЗС. Кастомное поле, отсутствует в стандартной схеме CRM Bitrix24 — уточнить через `crm.company.userfield.list` в портале-источнике. | 11067 GOLOVINSKAYA, 11122 PULKOVSKAYA, 02133 Ахметова, 11313 Сосногорск-1, 56043  Перовского |
| `comp_partner_name` | text | Название партнёра/группы АЗС. Кастомное поле, отсутствует в стандартной схеме CRM Bitrix24 — уточнить через `crm.company.userfield.list`. | Л-ЦНП, Лукойл Нептун, Л-УНП, Л-ЮНП, Л-ЦНП |
| `comp_region` | text | Регион расположения точки/АЗС. Кастомное поле, отсутствует в стандартной схеме CRM Bitrix24 — уточнить через `crm.company.userfield.list`. | Краснодарский край, Санкт-Петербург, Московская область, Москва, Москва |
